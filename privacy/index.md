# quikpik privacy policy

Last updated: August 22, 2026

quikpik is designed to work locally in the user's browser.

## Data quikpik handles

- Images and keywords deliberately added by the user.
- Theme, paste behavior and supported-website settings.
- Text entered into editable fields on enabled websites, processed temporarily to detect a matching keyword.

## Storage and transmission

Saved images and keywords are stored locally in Chrome's IndexedDB storage. Preferences are stored locally through the Chrome extension storage API. quikpik does not operate a server and does not sell, share or transmit this data to the developer or third parties.

quikpik does not encrypt the local image library. Anyone with access to the same unlocked Chrome profile or device may be able to access extension data, so users should not store sensitive images.

Typed text is inspected in the browser only to find a matching trailing keyword. It is not retained as chat history.

## Clipboard

When the user chooses a pic, quikpik writes that image to the clipboard so it can be pasted into the current chat.

## Website access

quikpik asks Chrome for permission before it runs on a supported website. When the user allows a website, quikpik can inspect editable text there temporarily to detect a matching trailing keyword and show the picker. The user can block or remove a website at any time in settings.

## Data deletion

Users can delete individual images and supported websites from the options page. Uninstalling quikpik removes extension-owned local data through Chrome.
